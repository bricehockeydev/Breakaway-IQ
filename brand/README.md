# Breakaway IQ brand assets

By Brice Hockey Development.

## Colors
- Navy   #0A2540  (primary / dark)
- Blue   #0F4C81  (secondary)
- Red    #E11D48  (accent)
- White  #FFFFFF

## Files
- `breakaway-iq-avatar-1080.png` — Instagram / social profile picture (navy square)
- `breakaway-iq-square-1080.png` — square post (navy, full lockup)
- `breakaway-iq-banner-1500x500.png` — Twitter/X header, YouTube-ish banner
- `breakaway-iq-icon-*.png/.svg` — the mark alone (navy square, or navy/white on transparent)
- `breakaway-iq-mark-white.svg` — mark, white, transparent (for dark backgrounds)
- `breakaway-iq-wordmark-navy/white.png/.svg` — "Breakaway IQ" text lockup
- `breakaway-iq-lockup.png` — mark + wordmark, white, transparent

SVGs are the source — scale to any size. Regenerate PNGs with `node brand/build.mjs`.
Type: Bahnschrift / DIN-style bold. Swap for a licensed display face later if desired.
